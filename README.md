# LX Music 桌面版 · 个性化改造版（v2.12.3）

基于开源音乐播放器 **LX Music 桌面版** 深度定制的一款增强版，在保留原版全部功能（多音源搜索、歌单、收藏、下载、多平台音源等）的基础上，对 **播放器界面、歌词体验、音频可视化、桌面歌词** 做了全新升级，并新增 **汽水音乐账号登录**。

---

## ✨ 更新与优化内容（v2.12.3）

### 一、视觉风格 —— 「Luminous Harmonic」玻璃拟态流光风

| 优化项 | 说明 |
|---|---|
| 流光动态背景 | 详情页背景采用流光层（径向渐变 + 缓慢旋转），随封面主色/主题色呼吸流动，毛玻璃质感 |
| 全界面玻璃化 | 顶栏、侧栏、播放栏均采用半透明毛玻璃（backdrop-blur），细描边玻璃高光，深浅主题自适应 |
| 统一图标与 Logo | 内置 SVG 图形，主题切换不丢图标 |

### 二、播放详情页（大改）

| 优化项 | 说明 |
|---|---|
| 封面动效 | 封面圆盘播放时顺时针旋转，暂停/停止自动静止；换歌有平滑过渡 |
| 环形音频频谱 | 频谱条紧密围绕封面圆盘外缘向外律动，暂停时频谱缓缓淡出消失；颜色跟随封面主色或主题色 |
| 背景取色双模式 | 设置中可选「适配主题色」或「根据封面取色」；选封面取色时，歌词已播放部分、频谱、播放控制、进度条、时间等全部自动适配当前歌曲封面主色，且始终保持清晰可读 |
| 主次歌词层次 | 当前句大字高亮、其他句小字淡显，视觉主次分明 |
| 歌词高亮模式可切换 | 设置中新增「歌词高亮模式」：**逐字高亮 / 逐行高亮 二选一**，切换即时生效，切歌、点词跳转后依然有效 |
| 清晰可读性 | 歌名、歌手、歌词、按钮文字均加柔光描边/阴影，任何背景色下都清晰 |

### 三、播放栏

| 优化项 | 说明 |
|---|---|
| 进度条波浪化 | 播放进度沿正弦波浪线前进，进度圆点沿波浪轨迹滑动，圆点始终为正圆并带光晕 |
| 配色跟随 | 播放详情页开启时，播放/暂停、上一首/下一首、进度条、时间跟随详情页取色；关闭详情页后恢复主题色 |
| 文字/图标清晰化 | 时间、按钮图标加投影，避免浅色背景看不清 |

### 四、桌面歌词（任务栏歌词）

| 优化项 | 说明 |
|---|---|
| 任务栏歌词条 | 歌词条可覆盖在屏幕底部任务栏左下角（不遮挡开始按钮），半透明置顶工具窗 |
| 双行歌词 | 左侧当前行 + 下一行预览，逐字高亮实时跟随播放进度 |
| 开关 | 主界面设置 → 桌面歌词 → 勾选开启 + 选择「歌词条」形态 |

### 五、其他功能

- **汽水音乐账号登录**：扫码登录后解锁汽水音乐音源内容
- **歌词进度点击**：点击歌词行可直接跳转播放进度（含进度微调面板）
- **用户数据保留**：可覆盖安装，设置/歌单/收藏全部保留在系统用户目录
- **便携/安装双版本**：提供 Setup 安装版、便携版、绿色 7z

## 📖 使用方法

### 安装
- **安装版**：运行 `lx-music-desktop-v2.12.3-x64-Setup.exe`，按向导安装（可自选目录）。
- **便携版**：解压 `-portable.exe` / 绿色 7z 到任意目录，双击 `lx-music-desktop.exe` 运行，数据保存在便携目录内。
- 覆盖安装旧版：直接运行新版 Setup 即可，设置与歌单自动保留。

### 常用入口
| 想做什么 | 操作路径 |
|---|---|
| 切换详情页背景取色模式 | 设置 → 播放详情页设置 → 详情页背景配色 → 适配主题色 / 根据封面取色 |
| 切换歌词高亮模式 | 设置 → 播放详情页设置 → 歌词高亮模式 → 逐字高亮 / 逐行高亮 |
| 调整歌词字号/对齐 | 播放详情页内按 `+` / `-` 键；或在歌词上右键菜单设置 |
| 打开桌面歌词条 | 设置 → 桌面歌词 → 开启桌面歌词，并把模式选为「歌词条」 |
| 显示/隐藏详情页 | 点击播放栏封面图进入；按键盘 `Esc` 或点击返回按钮退出 |
| 汽水音乐登录 | 侧边栏汽水音乐入口 → 扫码登录 |
| 点击歌词跳转 | 在详情页歌词上单击目标句即可跳转播放 |

### 快捷键速查
| 键 | 功能 |
|---|---|
| `Space` | 播放/暂停 |
| `Ctrl + →` / `Ctrl + ←` | 下一首 / 上一首 |
| `+` / `-` | 播放详情页内调整歌词字号 |
| `Esc` | 退出播放详情页 |

### 数据说明
- 播放设置、歌单、收藏等数据保存在系统用户目录（`%APPDATA%\lx-music-desktop`），**卸载或覆盖安装不会丢失**；请勿手动删除该目录。
- 若曾使用早期测试版，数据在程序目录 `data2` 下，可用新版「设置 → 数据导入」或手动复制到用户目录完成迁移。
