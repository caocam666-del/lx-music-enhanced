# v2.13.0 — 歌词灵动岛

> 发布日期：2026-10-18

这是本改造版第一个**大型功能版本**：把桌面歌词从"一根横条"升级为**贴着屏幕顶部居中的灵动岛**——收起时是一颗胶囊，鼠标移入（或点击）后展开成完整的播放卡，带滚动歌词、点击跳转、拖拽调宽。

另外修了一批长期存在的歌词与播放稳定性问题：任务栏歌词逐字高亮冻结、双击列表歌曲后秒切下一首、歌词条宽度调不动、切换歌词模式后宽度被重置等。

## 🏝️ 大改动：歌词灵动岛（全新）

![收起态胶囊](https://raw.githubusercontent.com/caocam666-del/lx-music-enhanced/v2.13.0/docs/images/island-collapsed.png)

| 能力 | 说明 |
|---|---|
| 收起态胶囊 | 封面 + 歌名/歌手 + 当前歌词行，胶囊宽度按内容自适应（也可拖拽边缘固定宽度） |
| 展开态播放卡 | 封面/歌名/歌手 + **3 行歌词** + 播放控制 + 通栏波浪进度条 |
| 两种展开方式 | 悬停展开（带 0-500ms 延迟可调）／ 点击展开（不响应鼠标经过） |
| 停靠边 | 顶部 / 底部 / 左侧 / 右侧，贴边位置与边距可调 |
| 点击歌词跳转 | 播放卡里的每一句都可点击，直接跳到该句时间 |
| 进度条拖动 | 波浪进度条支持点击/拖动定位，拖动时不会被自动切歌逻辑打断 |
| 滚轮调字号 | 鼠标停在歌词上滚动即可实时改字号（9–30px） |
| 流光背景 | 完全复刻详情页：封面取色 + 三圆斑遮罩 + 旋转纹理，可切「动态流光 / 拾音器律动 / 纯净」，流光强度与不透明度独立可调 |
| 颜色跟随 | 默认与详情页歌词同色，也可在设置里单独指定 |
| 歌词切换 | 纯淡入淡出，三行位置固定，不做上下滚动 |

> 展开高度与歌词字号、行数是联动的：**卡片完整显示 N 行歌词所需的最小高度 = 107 + 行数 × 字号 × 1.6**。
> 设置页会在高度偏矮时给出提示，避免最后一行被裁掉。

## 📊 中改动：任务栏歌词

| 项目 | 说明 |
|---|---|
| **加宽** | 默认宽度 450px → **660px**，歌词列可用宽度从约 240px 提升到 488px，24 字长句不再被截断 |
| **宽度可调** | 设置页新增「歌词条宽度」滑块（320–1200px），拖动即时生效 |
| **逐字高亮修复** | 之前逐字进度只走完前一两个字就冻结；现在能完整推进到整句结束（实测可到 100%） |
| **滚动更自然** | 与灵动岛统一的 360ms 上滚动画，去掉会让半行消失的边缘遮罩 |

## 🔧 小改动：稳定性与设置

| 类型 | 内容 |
|---|---|
| 播放 | **修复双击列表歌曲后播放失败并秒切下一首**：`play()` 的 `AbortError` 不再被当成播放失败；换源抖动期内（600ms）的瞬时错误忽略；自动切歌判定从 600ms 放宽到 1500ms，并要求播放器确实处于错误态 |
| 播放 | 取 URL 增加请求代次，旧请求的迟到结果不再覆盖当前播放 |
| 设置 | **修复歌词条宽度调不动 / 切换歌词模式后宽度被重置**：`desktopLyric.width/height` 不再被窗口实际尺寸回写 |
| 设置 | 修复「灵动岛停靠边 / 收起态宽度 / 边距 / 自适应宽度」改动后窗口不重排（此前是摆设） |
| 设置 | 修改歌词行数、字号后卡片高度会实时跟随 |
| 视觉 | 修复启动时灵动岛偶发"卡片内容被压成胶囊高度" |
| 视觉 | 修复展开态偶发只显示两行歌词 |
