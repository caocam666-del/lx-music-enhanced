## 2.12.5 — 歌词同步修复 · 排行榜修复 · 律动流光

本次发布集中修复了歌词与排行榜两个长期问题，并优化了详情页律动流光效果。

### 修复

- **修复 播放完自动切歌后歌词乱跳 / 跳到最后一句的问题**
  根因：歌词同步使用的时间被重复乘以 1000（内部时间已是毫秒又乘一次），导致换曲瞬间用一个极大的时间值定位歌词；歌词尚未就绪时该错误未被拦截，歌词会直接跳到末行。已修正全部相关位置并加强换曲残留时间的判别。
- **修复 手动拖到尾奏区间、或尾奏暂停再播放时，歌词跳回第一行**
  尾奏区间（最后一行歌词之后的纯音乐段）的位置属正常范围，不再被误判为异常而重置。
- **修复 排行榜无法切换 / 只显示一个榜单 / 音源下拉菜单空白**
  根因：路由组件的 key 使用了 `route.fullPath`，切换榜单或音源时整个页面被销毁重建，导致下拉标签、滚动位置与榜单状态全部丢失。已改为按路由路径复用组件。
- **修复 部分歌曲无法播放时卡住** — 播放出错时自动切换下一首（连续失败最多 3 次）。
- **修复 详情页封面外的多余留白与两圈白线** — 改为干净的旋转圆形封面。
- **修复 长句歌词显示不全** — 超长歌词行在容器内正常折行。
- **修复 详情页页面切换时整页空白**（弹窗挂载点引起的渲染中断）。
- **修复 Wallpaper Engine 壁纸重启后不自动加载、以及被自定义壁纸覆盖的问题。**
- **修复 使用动态壁纸后退出可能残留进程导致无法再次打开的问题。**
- **修复 启动时「当前已是最新版本」提示卡住不消失的问题。**
- **修复 网易云扫码登录二维码内容无效的问题。**

### 优化

- **详情页流光背景重构** — 参考 Pure music 的流光实现，改为视口固定的多层色斑 + 纹理缓慢旋转，摆脱「放大模糊封面」的观感，背景更干净自然。
- **节奏律动模式可见性提升** — 重做律动幅度与响应速度，流光随鼓点明显呼吸；同时限制刷新率并跳过无变化写入，消除卡顿。
- **歌词清晰度** — 仅当前行取色，已播放/未播放行保持干净的白色；歌词模糊化开关完全生效。
- **列表滚动体验** — 浏览列表时点击歌曲不再被强制跳回顶部，仅在切换榜单 / 歌单 / 翻页时回到顶部。
- **左上角图标** — 改为透明线性简笔音符，颜色跟随主题变化。
- **功能组件颜色** — 新增「乌漆麻黑」等主题色板与调色盘，可自由选择歌词高亮 / 进度条 / 按钮的强调色，并自动保证与背景的对比度。

### 新增

- **详情页「功能组件颜色」设置** — 封面取色 / 主题色板 / 自定义调色盘，作用于歌词高亮、进度条、播放控制与功能按钮。
- **详情页「节奏律动」流光模式** — 可在「动态流光 / 节奏律动」之间切换。
- **自动更新** — 检查更新与下载已绑定至本仓库。
